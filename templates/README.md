# Import Templates

Each entity has four files:

- `<entity>_template.csv`
- `<entity>_template.xlsx`
- `<entity>_dummy_20.csv`
- `<entity>_dummy_20.xlsx`

Recommended demo import order: Departments, Users, Approval Matrix, KPI Forms, KPI Points.

The KPI Points Excel template includes a dropdown for `calc_type`:

- `HIGHER_BETTER`
- `LOWER_BETTER`
- `MANUAL_SCORE`
