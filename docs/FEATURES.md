# Feature Map V2

## User and security

- Login melalui email, username, atau employee code
- Supabase Auth session dan refresh token
- Mandatory password change
- PostgreSQL Row Level Security
- Primary department dan related-department scope
- Runtime configuration guard, sehingga URL Supabase tidak pernah dibentuk dari nilai `undefined`

## KPI

- Monthly KPI worksheet
- Weighted KPI points
- Draft save dan submission
- Evidence upload ke private storage
- Calculation engine
- Approval history dan digital signature token
- Official PDF generation dan archive

## Approval

- Role-based queue
- Approve dan reject dengan mandatory note
- Multi-stage approval matrix
- Notifications
- Cursor-batched scoped reroute tanpa mengulang stage yang sudah selesai

## Administration

- Create dan update user
- Activate/deactivate user
- Safe hard delete user tanpa histori bisnis
- Reset password
- Related department access
- Import/export user CSV dan Excel
- Simplified UPSERT import for users, departments, approval matrix, KPI forms, and KPI points
- Automatic database resolution for IDs, identity snapshots, period keys, statuses, and calculated values
- 20-row dummy datasets and Excel calc_type dropdown
- Department update/delete
- Approval matrix management
- Audit trail
- Runtime/system health
- Settings
- First administrator bootstrap

## Executive experience

- Microsoft Fluent acrylic surfaces dan motion
- Apple-style whitespace dan typography
- Linear-style collapsible navigation with persisted sidebar preference
- Power BI-inspired KPI cards and charts
- Siemens-style manufacturing status and operational monitoring
- Banshu company logo on login, setup, sidebar, and application metadata
