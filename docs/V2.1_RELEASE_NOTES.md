# V2.1 Release Notes

## Import Center

Templates now contain only essential business input fields.

- Users: email, action, and related_department_codes removed. Email is generated automatically for new Supabase Auth users. Existing email is preserved.
- Departments: action removed.
- Approval Matrix: action removed and the six-stage route is explicit: Checked1, Approval1, Approval2, Approval3, Checked2, Approval4.
- KPI Forms: action, period_key, user_id, full_name, role_code, and status removed. Values are resolved from employee_code and period fields.
- KPI Points: action and form_id removed. form_no is resolved to form_id. The Excel template includes a calc_type dropdown.
- Import is UPSERT-only. Delete operations remain in dedicated administration screens.

## Dummy data

Every import entity includes a 20-row CSV and Excel dummy dataset. Import order:

1. Departments
2. Users
3. Approval Matrix
4. KPI Forms
5. KPI Points

The Import Center also provides a **Load Dummy 20** button.

## UI

- Sidebar can be minimized and expanded. Preference is stored in localStorage.
- Non-functional Control Center search was removed.
- My KPI summary cards use stronger contrast.
- Draft action dock is now light, readable, and clearer.
- Period selection uses a month calendar input.
